## 💼 Mitt första projekt – Portfolio

Det här är mitt första webbutvecklingsprojekt, där jag byggt en personlig portfolio med HTML, CSS och JavaScript. Syftet med projektet är att visa vem jag är, mina erfarenheter, intressen och varför jag valt att utbilda mig till fullstack JavaScript-utvecklare.

Projektet är även ett sätt att börja arbeta med moderna webbutvecklingsprinciper som responsiv design, tillgänglighet, bildoptimering och prestandaförbättringar (t.ex. Google Fonts optimering, lazy loading, responsive images m.m.).


## 🚀 Demo

[📎 Se sidan live](https://lindsteez.github.io/first-project/)

## 🛠️ Funktioner

📷 Bildkarusell med mina personliga intressen

🕓 Tidslinje med tidigare arbetslivserfarenheter

🔄 Flip-boxar som visar varför jag valt att bli utvecklare

🏢 Information om företag i Malmö som jobbar med JavaScript

👣 Scroll-to-top-knapp för bättre användarupplevelse

📱 Responsiv layout för både mobil och desktop

⚡ Prestandaoptimerad – 100/100 i Lighthouse Mobile Performance

## 🧰 Tekniker

🧱 HTML5

🎨 CSS3 (inkl. media queries, flexbox, box shadows, transitions)

💻 JavaScript

🖋️ Google Fonts (optimerat med preconnect, media="print" och onload)

🖼️ Responsive Images (<picture> + srcset)

🐢 Lazy loading av bilder

📊 Lighthouse-anpassningar (LCP, render-blocking m.m.)


## 📌 Att tänka på / Lärdomar

Hur viktigt det är att optimera bilder för olika enheter.

Hur små justeringar (t.ex. Google Fonts optimering) kan ge stora prestandavinster.

Vikten av tydlig kodstruktur med HTML-sektioner och semantik.

Hur IntersectionObserver och scrollTo() förbättrar användarupplevelsen.

Betydelsen av tillgänglighetsanpassningar som alt-texter och tangentbordsnavigation.
